Modern Excel 호환 패키지 (MECP)

Modern Excel Compatibility Pack (MECP)

구버전 Excel(2016, 2019, 2021)에 최신 날개를 달다

1. MECP란 무엇인가요? (왜 필요한가요?)

최근 업데이트된 Microsoft 365(최신 엑셀)에는 데이터를 강력하게 다룰 수 있는 훌륭한 신규 함수들(FILTER, XLOOKUP, UNIQUE, SORT 등)이 대거 추가되었습니다. 하지만 Excel 2016, 2019, 2021 등 구버전 엑셀에서는 이 함수들을 지원하지 않아 파일을 열면 #NAME? 오류가 발생하며 수식이 망가집니다.

MECP(Modern Excel Compatibility Pack)는 구버전 엑셀 사용자도 버전에 구애받지 않고 이 강력한 최신 함수들을 똑같이 사용할 수 있도록 만들어주는 추가 기능(Add-in) 플러그인입니다.

2. 포함된 함수 목록

MECP를 설치하면 구버전 엑셀에서도 다음 4가지 핵심 최신 함수를 사용할 수 있습니다. 기존 엑셀 함수와의 충돌을 방지하기 위해 함수 이름 맨 앞에 소문자 a가 붙습니다.

  • 🔥 aFILTER: 지정한 조건에 맞는 데이터만 깔끔하게 추출합니다.
  • 🔥 aXLOOKUP: VLOOKUP의 완벽한 상위 호환! 좌우 상관없이 표에서 원하는 데이터를 정확히 찾아옵니다.
  • 🔥 aUNIQUE: 데이터 목록에서 중복을 제거하고 고유한 값(리스트)만 쏙 뽑아냅니다.
  • 🔥 aSORT: 데이터를 원하는 열을 기준으로 오름차순이나 내림차순으로 자동 정렬합니다.

3. 1초 자동 설치 방법

엑셀의 복잡한 "개발자 도구"나 "보안 센터" 설정은 전혀 필요 없습니다. 클릭 한 번으로 설치가 완료됩니다!

  1. 하단의 다운로드 버튼을 눌러 압축 파일을 받습니다.
  2. 다운로드 받은 폴더의 압축을 풉니다.
  3. 폴더 안에 있는 Install_MECP.vbs 파일을 마우스로 더블 클릭합니다.
    (주의: 반드시 MECP.xlam 파일이 같은 폴더에 있어야 합니다.)
  4. 1~2초 뒤 화면에 "설치가 성공적으로 완료되었습니다!"라는 창이 뜨면 [확인]을 누릅니다.
  5. 이제 모든 설치가 끝났습니다! 평소처럼 엑셀을 열고 사용하시면 됩니다.

4. 실전 사용 방법 및 예시

엑셀의 아무 셀에나 = 기호를 입력하고 a를 입력해 보시면 설치된 함수들이 도움말과 함께 나타납니다. 기존 M365 최신 함수와 문법이 100% 동일합니다.

💡 aFILTER (데이터 필터링)

=aFILTER(가져올범위, 조건범위="조건")

예시: `=aFILTER(A2:C100, B2:B100="서울")`
설명: B열의 지역이 "서울"인 사람들의 A열부터 C열까지의 데이터를 전부 가져옵니다.

💡 aXLOOKUP (데이터 찾기)

=aXLOOKUP(찾을값, 찾을범위, 가져올범위)

예시: `=aXLOOKUP(F2, A2:A100, C2:C100, "없음")`
설명: F2 셀에 적힌 사번을 A열에서 찾아서, 해당 사람의 C열 연락처를 가져옵니다. 못 찾으면 "없음"으로 표시합니다.

💡 aUNIQUE (중복 제거)

=aUNIQUE(범위)

예시: `=aUNIQUE(B2:B100)`
설명: B열에 적힌 수많은 부서명 중 중복을 제외하고 고유한 값 목록만 한 번씩 출력합니다.

💡 aSORT (데이터 정렬)

=aSORT(범위, 정렬기준열, 오름차순/내림차순)

예시: `=aSORT(A2:C100, 3, -1)`
설명: A열부터 C열까지의 데이터를 통째로 가져와 3번째 열(C열)을 기준으로 내림차순(-1) 정렬하여 보여줍니다.

🚀 호환성 팁: 만약 여러분이 나중에 최신 버전의 Microsoft 365 엑셀이 깔린 PC로 컴퓨터를 바꾸더라도, 이 함수들은 엑셀 내장 함수를 자동으로 감지하여 더 빠르게 동작하므로 문서를 수정할 필요가 전혀 없습니다!
