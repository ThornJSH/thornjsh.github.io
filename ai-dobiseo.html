도비서의 8가지 핵심 기능

📅

자연어 일정 등록 및 동기화

"내일 3시 팀 회의", "11월 15일 워크숍 종일"처럼 일상 언어로 편하게 전달하면 시간과 장소를 자동 파악하여 캘린더에 즉시 등록합니다.

🔄

캘린더 ↔ 시트 양방향 동기화

시트에서 행을 수정하면 캘린더에, 캘린더에서 수정한 내용은 시트에 자동으로 상호 반영됩니다. 시트에서 '삭제' 입력 시 캘린더에서도 자동 삭제됩니다.

📝

스마트 할 일(To-Do) 관리

구체적인 날짜 없이 "~까지" 기한만 있는 업무나 마감 건은 일정이 아닌 '할 일 목록' 탭으로 자동 저장되며 /todo로 완료 체크가 가능합니다.

🕒

캘린더 빈 시간 자동 탐색

"다음 주에 2시간 비는 시간 찾아줘"라고 요청하면 평일 업무 시간(09:00~18:00) 기준으로 기존 일정을 피해 비어 있는 시간대를 코드가 직접 계산해 안내합니다.

☀️

아침/저녁 정기 일정 브리핑

매일 아침 07시 오늘 하루 일정과 마감 임박 To-Do를, 저녁 17시에는 다음 날부터 7일간의 주간 일정을 자동으로 요약 발송합니다. (시각 변경 가능)

⏰

일정 직전 사전 알림 & 완료 확인

시간 일정이 시작되기 1시간 전에 잊지 않도록 알림을 보내며, 매일 저녁 19시에는 오늘의 일정을 정상 완료했는지 버튼으로 피드백을 수렴합니다.

💡

아침 AI 상황 점검 (Insight)

아침 브리핑 발송 후, 앞으로의 일정과 미완료 할 일을 Gemini가 종합 분석하여 오늘 놓치기 쉬운 준비사항 최대 3가지를 조언합니다.

🔎

원클릭 링크 & 자료 검토 목록

업무 중 나중에 읽을 웹 링크(URL)나 "검토: 운영위 자료"를 보내면 Gemini 호출 없이 검토 목록 탭에 깔끔하게 보관하고 목록(/review)을 제공합니다.

도비서 실전 활용 가이드

1. 일정 등록 & 수정

말로 등록하고 말로 변경하기

  • 일정 등록: "내일 오후 2시 복지관 2층에서 후원위원회 회의"
  • 종일 일정: "11/20 직원 워크숍"
  • 일정 변경: "후원위원회 회의 3시로 바꿔줘" ➔ 확인 버튼 클릭
  • 일정 삭제: "내일 2시 회의 취소해줘" ➔ 삭제 버튼 클릭
2. 빠른 조회 & 빈 시간

Gemini 호출 없이 1초 즉시 확인

  • 빠른 브리핑: "오늘 일정", "내일 일정", "이번주 일정"
  • 빈 시간 찾기: "목요일 오후에 1시간 비는 시간 있어?"
  • 기간 지정: "다음 주에 3시간 회의 잡을 만한 시간 찾아줘"
3. 할 일 & 검토 목록

기한 관리와 자료 스크랩

  • 기한 할 일: "보고서 금요일까지", "할 일: 소식지 원고 작성"
  • 완료 처리: "보고서 끝냈어", "소식지 완료" 또는 /todo
  • 링크 보관: 링크 URL을 봇에게 전송 ➔ /review로 확인
4. 에이전트 대화 모드

맥락을 유지하는 심층 비서

  • 호출어: "도비서야", "도비서님" 또는 /비서
  • 복합 질의: "이번 주 일정 중에 외부 출장 겹치는 날 언제야?"
  • 대화 종료: "끝", "고마워 종료" 입력 시 맥락 종료

📌 텔레그램 필수 명령어 치트시트

명령어 설명 비고
/today 오늘 하루 전체 일정 즉시 요약 조회 Gemini 토큰 미소모 (즉시 답장)
/week 앞으로 7일간의 다가오는 일정 목록 조회 날짜별 정렬 출력
/todo 남은 할 일 목록 확인 및 원클릭 [✅ 완료] 버튼 시트 '할일목록' 연동
/review 보관된 링크/자료 검토 목록 및 [완료] 버튼 시트 '검토목록' 연동
/setup 브리핑 시각, 알림 시간, 각 기능 On/Off 대화형 설정 시트 코드 수정 불필요
/check 오늘 진행한 일정 완료 여부 수동 점검 [완료] / [미완료] 버튼
/pending 처리하지 않고 지난 일정 모아보기 및 재조정 날짜변경 / 할일로 이동 지원
/remindon / /remindoff 일정 시작 1시간 전 알림 켜기 / 끄기 설정창에서 분 단위 조절 가능
/insighton / /insightoff 아침 AI 상황 점검 기능 켜기 / 끄기 기본 활성화

3분 만에 나만의 도비서 만들기

스프레드시트 사본 복사와 키 입력만으로 즉시 구동됩니다.

1

스프레드시트 사본 복사

아래 배포용 구글 스프레드시트 링크에 접속하여 본인의 구글 드라이브로 [사본 만들기]를 실행합니다.

📄 도비서_일정관리 시트 사본 복사하기 ➔
2

텔레그램 봇 토큰 발급 (BotFather)

텔레그램 검색창에서 @BotFather와 대화를 시작한 후 /newbot 명령어로 본인만의 봇을 만듭니다. 발급된 API Token(숫자:문자열)을 복사해 둡니다.

3

Google Gemini API Key 발급

Google AI Studio에 접속하여 무료 API Key를 생성합니다. (Google 계정만 있으면 1분 내 무료 발급 가능)

🔑 Google AI Studio 바로가기 ➔
4

시트 메뉴에서 연결 & 자동 실행 시작

사본 시트를 열고 상단 메뉴 [도비서] ➔ [최초 설정 / 연결 설정]을 클릭합니다.
연동할 구글 캘린더를 선택하고, 봇 토큰과 Gemini API 키를 입력한 뒤 [설정 저장] ➔ [연결 확인] ➔ [자동 실행 시작]을 누르면 모든 설정이 완료됩니다!
